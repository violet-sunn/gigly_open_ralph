# GIGLY

B2B-биржа фриланс-задач («гигов») для российского IT-рынка. Связывает **Клиентов** (юрлица, публикуют задачи) и **Специалистов** (исполнители). Тёмная/светлая тема, синий бренд-акцент, пиксельно-моноширинная типографика. Только Desktop.

Источник истины по дизайну — приложенный Figma-файл. Этот проект — его перенос «как есть» + доработка в рабочий, прокликиваемый фронтенд, готовый к интеграции с бэкендом.

## Документы для разработки
- **`DATA-MODEL.md`** — сущности, поля, перечисления (схема БД).
- **`ROUTES.md`** — все экраны, состояния, навигация по ролям.
- **`HANDOFF.md`** — тех-заметки, ограничения, как устроены темы/иконки/шрифты, что мок vs реальное.
- **`ТЗ — Светлая тема.md`** — обоснование дизайн-решения светлой темы.

## Файлы-артефакты
```
Gigly App.dc.html          — интерактивный прототип (обе роли + админ, весь функционал)

Gigly Design System.dc.html— инвентарь: компоненты, токены, цвета, иконки

Онбординг.dc.html          — онбординг

  fig-tokens.css            — 189 токенов, темы Light/Dark/IC
```

## Роли
- **Специалист** — ищет гиги, откликается (подход/вопросы/оценка), выполняет, сдаёт работу.
- **Компания (Клиент)** — создаёт гиг (гайдед-бриф), смотрит отклики, назначает, принимает работу, отмечает оплату.
- **Админ (Модератор)** — консоль: пользователи (блокировка), гиги (закрытие), очередь споров (решение), журнал.

Переключение ролей — в сайдбаре (для демо). В проде роль определяется аккаунтом.

## Жизненный цикл гига
`Открыт → На рассмотрении → В работе → На проверке → Завершён → Оплачен` · ветка `Отклонён`.
Действия по правам: сдаёт работу только исполнитель, принимает/оплачивает только заказчик.

## Темы
Тёмная (дефолт) и светлая. Переключатель в Настройки → Внешний вид; выбор в localStorage (`gigly-theme`), применяется на `<html data-theme>`. Детали — в `HANDOFF.md`.
