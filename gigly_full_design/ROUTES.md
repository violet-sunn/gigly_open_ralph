# GIGLY — карта роутов и состояний

Прототип — одностраничный (`Gigly App.dc.html`), навигация через внутренний `state.route` + `state.role`. Дип-линк-хук `window.__giglyGo({role, route, gig, stage, dispute, modal, tab, applied})` используется развёрткой и для проверки.

## Ключевые состояния экранов

**Поиск** — фильтры: категория, бюджет (до 50к / 50–150к / 150к+), сортировка (новизна / дороже / дешевле); пустое состояние «Ничего не нашлось» + сброс; скелетоны при загрузке.

**Мои гиги** — табы по статусу (Все / Заявки / В работе / На проверке / Завершённые); пустое состояние; скелетоны.

**Деталь гига (`gigDetail`)** — панель действий зависит от роли × статуса:
- Открыт: спец → форма отклика (подход/вопросы/оценка, withdraw); компания → «Смотреть отклики».
- В работе: спец → «Сдать работу»; компания → «Специалист в работе».
- На проверке: компания → «Принять» / «Вернуть на доработку»; спец → «Работа на проверке».
- Завершён: компания → «Отметить как оплаченный»; спец → ждёт оплаты.
- Оплачен / Отклонён: терминальные плашки.
- В работе/на проверке — ссылка «Открыть спор».

**Создание гига (`createGig`, компания)** — гайдед-бриф: что сделать / как поймём что готово (DoD: цель, результат, конструктор критериев «Готово, когда…») / что учесть / условия; панель «Готовность брифа» (счётчик + подсказки); живой расчёт бюджет→сбор 10%→итого; экран успеха.

**Отклики (`applications`, компания)** — карточки специалистов (подход/вопросы/оценка) → Принять (назначает, остальные отклоняются) / Отклонить.

**Чаты** — список диалогов (переключение, свой тред у каждого), отправка (Enter/кнопка).

**Финансы** — ролевая сводка (спец: заработок; компания: расход + сбор) + список операций по статусам.

**Споры** — список; деталь (таймлайн сторон + доказательства + ответ модератору); открытие спора (причина + описание).

**Модерация (админ)** — статистика; очередь споров → экран решения; пользователи (блок/разблок); гиги (закрыть); журнал модерации (живой).

**Профиль** — спец: стек / опыт / категории (редактирование в модалках); компания: название / ИНН / КПП / о компании (редактирование).

## Глобальные оверлеи
Подтверждения (деструктивные действия), тосты (успех), дропдаун уведомлений (колокольчик), модалка настроек (шестерёнка), модалки редактирования профиля.
