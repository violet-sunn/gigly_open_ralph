# Project Context

Gigly is a web application built with modern web technologies.

## Stack
- Language: TypeScript
- Framework: Next.js 15+ (App Router)
- Database: Prisma with SQLite
- Styling: Tailwind CSS
- Package manager: npm

## Conventions
- Code style: TypeScript strict mode, ESLint
- Testing: Visual verification with agent-browser, unit tests as needed
- CI: TBD
- Authentication: Server Actions for auth operations
- File structure: Next.js App Router conventions

## Architecture
- App Router with server components by default
- Server Actions for mutations
- Prisma for database access
- SQLite for local development
