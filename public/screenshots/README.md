# Screenshots Directory

This directory contains screenshots of the Gigly platform for documentation purposes.

## Required Screenshots

The following screenshots need to be captured manually:

1. **gig-browsing.png** - Specialist gig browse page showing filters, search, and gig list
2. **gig-detail.png** - Gig detail page with applications and messaging
3. **gig-creation.png** - Gig creation form with all fields
4. **dashboard-client.png** - Client dashboard with "My Gigs" list
5. **dashboard-specialist.png** - Specialist dashboard with tabs
6. **application-form.png** - Application submission form with structured fields

## How to Capture Screenshots

1. Start the development server: `npm run dev`
2. Log in with seed accounts (see README.md for credentials)
3. Navigate to each page and capture screenshots at 1920x1080 resolution
4. Save as PNG files with the names listed above
5. Crop to remove browser chrome and focus on content
