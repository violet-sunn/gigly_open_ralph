# Screen frame reference renders

The in-hand SVGs (`screens/tokens.svg`, `screens/frames.svg`) contain the **component library**, not the
assembled screens. The `*.lossy.jpg` files here are the **lossy** screen mockups copied from `screens/*.jpg`
as an interim baseline. **High-fidelity per-screen frames must be exported from Figma** (residual gap — see
`docs/DESIGN_SPECS.md` §7). Do not treat these JPGs as pixel-accurate fidelity baselines.
