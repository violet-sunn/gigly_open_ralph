# Gigly — agent instructions

All routing lives in `CLAUDE.md` in this directory. Read it fully before any work; it names the single source of truth for behaviour (`openspec/specs/`), for visuals (`DESIGN.md`), the ralphy-spec workflow, which skill applies in which screen mode, and what to do when the rules are silent.

This file exists only so that agents which look for `AGENTS.md` find the same instructions. Do not add rules here; add them to `CLAUDE.md`.
